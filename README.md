# Sistem Peringatan Dini Mahasiswa

Aplikasi berbasis web menggunakan Flask untuk monitoring
akademik dan kehadiran mahasiswa.

## Fitur

- Dashboard mahasiswa
- Data mahasiswa
- Filter program studi
- Detail mahasiswa
- Pencarian berdasarkan NIM
- API data mahasiswa dalam format JSON
- Halaman error 404

## Teknologi

- Python
- Flask
- HTML
- CSS
- Jinja2
